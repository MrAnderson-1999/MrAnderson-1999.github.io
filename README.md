# Leon Avshalom — Resume

Personal resume site, served by GitHub Pages at https://mranderson-1999.github.io/

- `index.html` — the whole site: a single static page with inline CSS and no build step
- `resume.pdf` — the downloadable CV, kept in sync with the page
- `profile.jpeg` — portrait

To update, edit `index.html`, replace `resume.pdf`, and push to `main`.
